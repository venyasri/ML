How it works

Each measurement is standardized, multiplied by a learned weight and summed. A sigmoid turns the total into the probability that the wine is white. The confidence is the larger of P(white) and P(red). The explanation lists the features with the largest weight × value contribution.

The model is logistic regression with an penalty, chosen with 5-fold cross-validation. Regularization limits overfitting and, at stronger settings, selects features.

Who can use it

  • Wineries and QC labs: audit batches for mislabelled or mixed-up samples.
  • Retailers and importers: sanity-check supplier data before listing.
  • Analysts: screen large measurement files in seconds.
  • Students and teachers: see how regularized logistic regression decides, feature by feature.

Data

UCI Wine Quality dataset (Cortez et al., 2009): Portuguese Vinho Verde wines, 11 chemical features. After removing duplicate rows: wines, split 80% train / 20% test (stratified). The quality score is not used. One engineered feature, free-to-total SO₂ ratio, is added.

Screening aid for learning purposes, not a certified lab method.
